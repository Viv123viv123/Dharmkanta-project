# श्री गणेश पब्लिक धर्मकांटा

Static landing page for the [Shree Ganesh Public Dharmkanta Website](dharmkanta-project.vercel.app), a commercial weighing service located near Sushila Renu Cold Storage, Kabir Chowk, Narhan-Singhiyaghat-Rosera Road, Bihar.


## Overview

This project contains a single HTML page built with:

- `index.html` as the main site file
- Tailwind CSS via CDN for responsive styling
- Font Awesome icons for navigation and contact links
- Google Fonts for Devanagari typography

The page is written in Hindi and includes a polished mobile-first experience with the following sections:

- Hero section with image and Google Maps link
- Contact section with phone and WhatsApp links for owner and munshi
- Rate chart section for weight service pricing
- Specialties section highlighting business services
- Gallery section for business images

## Features

- Responsive navigation menu with mobile hamburger toggle
- Smooth reveal animation for content cards
- Calls-to-action for Google Maps and WhatsApp contact
- Clean branding in Hindi with custom fonts
- Lightweight single-page implementation using only HTML and external CSS/JS CDNs

## Usage

1. Open `index.html` in a modern browser.
2. Use the navigation links to jump to sections like संपर्क करें, रेट लिस्ट, विशेषता, and गैलरी.
3. Tap phone or WhatsApp buttons to contact the business directly.
